# 🦊 Weird But Good Recipes

By **Brycen Perina** (age 11) — live at [weirdbutgood.recipes](https://www.weirdbutgood.recipes)

A site of 150+ hand-drawn recipe cards I made — weird drinks, weird foods, weird snacks. Categories like 🍬 Candy, 😬 Sour, 🥨 Crunchy, 🧀 Cheesy, 🌙 Late Night, 🎮 Gamer Fuel, 🥶 Frozen, 🌭 Junk Food, and more.

## Features
- 150+ recipes with hand-drawn AI-illustrated cards (made via Gemini 3 Pro Image)
- Per-recipe pages with ingredients, steps, schema.org Recipe data
- 5 long-form blog posts (Energy Drinks, Spicy, Healthy Snacks, Coffee, Mocktails, Weirdest)
- PWA (install to home screen)
- Friend Cook-Off feature (1v1 AI-judged cooking battles)
- Photo-to-recipe (snap your fridge, get a recipe)
- Tip jar (Cash App + Tendy)
- Live stats dashboard

## Built With
- Static HTML + vanilla JS
- Vercel hosting
- Gemini for AI image gen + chat
- Schema.org structured data
